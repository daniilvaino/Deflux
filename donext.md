## Сделано (2026-08-16)

Починен UTF-8 чекпоинт в `src/Deflux.Core/Xml/MinimalXmlParser.cs` — 2 правки, внесены
руками, **не закоммичено**:

- `GetUnconsumedBytes` — незавершённый UTF-8 хвост копируется ПОСЛЕ перекодированных
  символов, а не перед ними (он последнее, что декодер откусил от потока).
- `RestoreState` — `_incompleteUtf8Len = 0`; хвост уже лежит в `PendingDecompressedBytes`
  и приходит через `Feed()`, повторное восстановление дублировало байты.

Проверено на репро из присланного fix-kit (сам kit удалён как отработанный).
Репро генерировало данные детерминированно, так что при необходимости
воспроизводится с нуля: A — документ из 800 узлов `<i>яяяяNNNN</i>` с подбором
padding так, чтобы байты 8191/8192 разрезали двухбайтовый символ, чекпоинт после
каждого узла, сверка хвоста с baseline; ProdSim — 50 листов по 250 строк
русского текста (`Random(42)`), один reader, `GetSheetNames()` + `OpenSheet(i)`

## Очередь

- [ ] **P1. Bump версии чекпоинта** в `CheckpointSerializer` — только если блобы
      персистятся между процессами. Старые блобы записаны с неверным порядком байтов,
      патч их не лечит; version bump уронит их в `CheckpointVersionException`,
      который `OpenSheet` перехватывает → медленный fallback вместо тихой порчи.
      Если чекпоинты живут только внутри процесса — пропустить.

- [ ] **P2. ODS: `number-rows-repeated` у НЕпустых строк теряет данные.**
      Репро (часть C) даёт 2 строки вместо 4, сумма 16 вместо 30. Починить
      `OdsReader.ReadRow`: либо выдавать строку N раз (остаток повторов в состоянии
      + учесть в чекпоинте), либо честно задокументировать. LibreOffice реально
      пишет repeated для одинаковых соседних строк.

- [ ] **P2. XLSX: ячейки без атрибута `r`** схлопываются в колонку 0 (часть D:
      100/200/300 все попадают в колонку 0). Фикс — бегущий счётчик `prevCol + 1`
      в `ParseCell`; спека позволяет опускать `r`.

- [ ] **P3. DynHeader: восстановление meta-дерева.** `CodeLengths` — переиспользуемый
      буфер; на стадии `DecodeDataLengths` он уже перезаписан, а `RestoreDynHeaderState`
      пересобирает из него meta-дерево. Живого репро нет и не воспроизводили.
      Фикс — хранить 19 meta-длин отдельным полем в `InflaterDynHeaderState`.

- [ ] **P3. Тесты/CI.** Перенести brute-force (часть A) в `Deflux.Tests`: чекпоинт после
      каждого узла на данных с кириллицей/эмодзи, сравнение хвостов с baseline.
      Добавить workflow `dotnet test` на push/PR — сейчас есть только publish-nuget.

- [ ] **Ops.** Грепнуть прод-логи на `XmlParseException` из `OpenSheet`/`ReadRow` —
      оценить, случалось ли уже. Тихая порча тоже возможна (если разрыв попал в текст
      ячейки, а не в разметку) — при подозрении сверить выборку нарезанных листов
